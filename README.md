# efsosud-rgb.github.io

Portfólio de Eric Oliveira, publicado em https://efsosud-rgb.github.io

O código dos sistemas mostrados fica em repositórios privados. A tela real do Wings System tem os dados de clientes borrados; as do Moleka PDV, do TF Pipas e do Controle de Despesas são reais, com dados fictícios de demonstração; a imagem da Still Fit é um quadro do render em Blender; as ilustrações 3D de Mário Gás, Amarjon Biojoias e Lion Eletroposto não são telas dos sistemas; as demais são reproduções com dados fictícios.
